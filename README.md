# Talk Tracker

A web application for tracking conference talks, built with Vaadin 25 and Spring Boot 4.

## Tech Stack

- Java 25
- Spring Boot 4.0
- Vaadin 25.1
- Spring Data JPA with H2 database

## Prerequisites

- Java 25+

## Build

```bash
./mvnw clean package
```

## Run

```bash
./mvnw spring-boot:run
```

The application will be available at [http://localhost:8080](http://localhost:8080).
